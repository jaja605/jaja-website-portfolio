## 🛠️ Local Development Setup

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **pnpm** or **yarn**
- **Git**

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_GITHUB_USERNAME/portfolio-3d.git

# Enter project directory
cd portfolio-3d

# Install dependencies
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production build will be output to the `dist/` directory.

---

## 🌐 Deploy to Vercel

1. Push this project to your GitHub account (see step-by-step instructions in docs).
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** > **"Project"**.
4. Select your `portfolio-3d` repository.
5. Preset settings:
   - **Framework Preset**: Vite
   - **Root Directory**: `./`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Click **Deploy**!
